# 03 — Roles, users, policies (IAM)

This lab builds the two halves of IAM: an execution **role** trusted by the
Lambda service, and a programmatic **user** with a generated access key. Both
get least-privilege policies authored inline from Terraform, and everything is
inspected through the IAM CLI on the Floci emulator.

## What you'll learn

- Difference between an IAM **role** (assumed by services/principals) and an IAM **user** (static identity)
- Writing a **trust policy** via `assume_role_service`
- Attaching **AWS-managed policies** vs authoring your own **inline policy JSON** with `jsonencode`
- Why a generated secret is marked `sensitive` in outputs

## Resources created

- Role `astrolumina-learning-app-role` — trusted by `lambda.amazonaws.com`, attached `AWSLambdaBasicExecutionRole`, inline `s3-read` policy (`s3:GetObject` only), tags `Environment=learning`, `lab=03-iam`
- User `astrolumina-learning-app-user` — attached `ReadOnlyAccess`, one generated access key, tags `Environment=learning`, `lab=03-iam`

> ⚠️ **Floci dummy credentials, never reuse.** The access key Terraform prints
> here is generated by the local emulator and has zero value outside it. Never
> hardcode a secret in code or commit one to git — on real AWS, prefer roles
> and short-lived sessions over user access keys.

## Run it

```bash
cd labs/03-iam
terraform init
terraform apply
```

Print the (dummy) generated credentials with:

```bash
terraform output --raw secret_access_key
```

## Verify

One-time environment setup (dummy Floci credentials, region, and endpoint):

```bash
export AWS_ACCESS_KEY_ID=111111111111 AWS_SECRET_ACCESS_KEY=test AWS_DEFAULT_REGION=us-east-1 AWS_ENDPOINT_URL=http://localhost:4566
```

Inspect the role's trust policy, its attached policies, the user and its keys:

```bash
aws --no-cli-pager iam get-role --role-name astrolumina-learning-app-role
aws --no-cli-pager iam list-attached-role-policies --role-name astrolumina-learning-app-role
aws --no-cli-pager iam list-users
aws --no-cli-pager iam list-access-keys --user-name astrolumina-learning-app-user
```

The Floci dashboard at http://localhost:8080 shows the same IAM objects under
**IAM**.

## Destroy

```bash
terraform destroy
```
